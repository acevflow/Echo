# Contributing to Echo

Thank you for your interest in Echo! We welcome contributions to help make this local music player better for everyone.

Echo is a modern Android music player focused on providing a clean, fast, and pleasant experience for playing music stored directly on the user's device.

## How to Get Started

1.  **Fork the repository** on GitHub.
2.  **Clone your fork** locally: `git clone https://github.com/your-username/echo.git`
3.  **Create a new branch** for your feature or bug fix: `git checkout -b feature/your-feature-name`
4.  **Set up the development environment**: Ensure you have the latest stable version of Android Studio installed.
5.  **Make your changes**, ensuring you follow the project's coding standards.

## Reporting Bugs

If you find a bug, please open a GitHub issue and include:

*   A clear and descriptive title.
*   Steps to reproduce the problem.
*   Expected and actual behavior.
*   Device information (model, Android version).
*   Logs or screenshots if applicable.

## Suggesting Features

We are open to feature suggestions! Please open an issue to discuss your ideas before starting implementation.

## Submitting Pull Requests

1.  Ensure your code is clean, readable, and follows the existing project architecture.
2.  Include relevant tests for your changes.
3.  Update documentation if necessary.
4.  Write clear, concise commit messages.
5.  Push your branch to GitHub and open a Pull Request against the `main` branch.

## Code Quality and Guidelines

*   **Architecture**: Follow clean architecture principles and separation of concerns.
*   **Style**: Use idiomatic Kotlin and follow standard Android development conventions.
*   **Documentation**: Add KDoc comments for non-trivial public APIs and internal logic.
*   **Testing**: We aim for high test coverage. Please include unit tests for business logic and UI tests for critical user flows.

## Development Guidelines

*   Do not add unnecessary dependencies.
*   Prioritize performance and low resource usage.
*   Ensure accessibility (a11y) is considered in UI changes.
*   Maintain user privacy and security at all times.

Thank you for helping us build Echo!
